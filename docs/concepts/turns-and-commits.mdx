# Turns and Commits

T3X separates source history from reviewed semantic state.

## Turns

A turn is one source event: a message, assistant response, tool result, or other
piece of source material. Turns preserve provenance so committed knowledge can
trace back to evidence.

## Commits

A commit is a reviewed snapshot of semantic content:

```json
{
  "schema": "t3x/commit",
  "parents": ["sha256:..."],
  "content": {
    "trees": [],
    "relations": []
  }
}
```

The hash covers first-class semantic fields, so the same reviewed content
produces the same commit identity.

## Practical habit

Use turns as evidence. Use commits as durable checkpoints.
