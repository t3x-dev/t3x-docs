# Semantic Content

T3X stores reviewed meaning as structured YAML-shaped content, not as raw chat
transcripts. Source material stays visible, but the committed state is a
knowledge tree plus relations.

## Source, meaning, commit

| Stage | Purpose |
| --- | --- |
| Source | Preserve the original text, prompt, notes, or transcript. |
| Meaning | Extract facts, decisions, risks, constraints, and relations. |
| Commit | Store a reviewed semantic snapshot with a hash. |

## Why this matters

Text can change without changing meaning, and meaning can change without large
text edits. T3X is designed to track the latter: what changed in the knowledge
you want to keep, review, compare, and reuse.

## Deterministic mutation

LLMs may propose YOps, but they do not mutate committed state directly. The
YOps engine validates and applies operations deterministically.
