# Import and Export

T3X is designed around portable semantic content.

## Import

Source material can come from prompts, chat transcripts, release notes, meeting
notes, specs, or other text-heavy workflows. The WebUI keeps source material
visible while meaning is extracted and reviewed.

## Export

Committed knowledge should remain useful outside the first workspace. Export
formats and integrations may evolve during alpha, but the core expectation is
stable: source evidence, semantic trees, relations, and commit identity should
travel together.

## Current alpha scope

For restricted alpha usage, start with `@t3x-dev/local` and `@t3x-dev/yops`.
