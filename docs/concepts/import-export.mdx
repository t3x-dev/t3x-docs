# Import and Export

T3X is designed around portable structured state.

## Import

Source material can come from prompts, chat transcripts, release notes, meeting
notes, specs, or other text-heavy workflows. The WebUI keeps source material
visible while YOps proposals and state changes are reviewed.

## Export

Committed state should remain useful outside the first workspace. Export formats
and integrations may evolve during alpha, but the core expectation is stable:
source evidence, reviewed YOps, structured YAML state, provenance, and commit
identity should travel together.

## Current alpha scope

For alpha usage, start with `@t3x-dev/local` and `@t3x-dev/yops`.
