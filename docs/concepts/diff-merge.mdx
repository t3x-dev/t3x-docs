# Diff and Merge

T3X compares semantic content rather than only text.

## Diff

A semantic diff answers questions like:

- Which decisions were added?
- Which constraints disappeared?
- Which risks changed wording but kept the same meaning?
- Which relation now contradicts another relation?

## Merge

A merge combines two semantic histories. Identical content can be kept
automatically. Similar or conflicting content should be reviewed before it
becomes a new commit.

## Review is the point

T3X is not trying to hide ambiguity. It surfaces change and conflict so a human
or agent can decide what should become durable knowledge.
