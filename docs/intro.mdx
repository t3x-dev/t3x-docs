# T3X

<DocBadges status="alpha" verified="verified" />

T3X is a structured source of truth for AI work. It keeps the original source
text, extracts reviewable meaning into YAML-shaped knowledge, mutates that
knowledge only through YOps, then saves it as commits that can be inspected,
diffed, merged, and reused.

The shortest way to understand it:

```text
source text -> YOps proposal -> reviewed tree -> commit -> leaf output
```

This is not a markdown dump and not a chatbot transcript archive. T3X is built
for the point where AI output needs to become trusted, replayable project
knowledge.

![T3X chat landing](/img/screenshots/chat-light.png)

## What T3X Gives You

| Surface | What it does | Value |
| --- | --- | --- |
| WebUI | Chat, review YOps, inspect Canvas, create Leaf output | Turns loose AI work into an auditable workflow |
| YOps | 18 declarative YAML operations | Makes every tree mutation reviewable and replayable |
| Local alpha | Packaged local entrypoint | Runs the self-hostable product without assembling every package manually |
| CLI | Preview command path for project -> draft -> YOps -> commit -> leaf | Lets scripts and terminal users drive the same state machine |
| MCP | Preview agent interface with 8 umbrella tools | Lets AI agents capture, edit, commit, diff, merge, and generate through T3X |
| API | Hono route library and standalone server | Provides the self-hosted backend and extension point for cloud |

## The Core Rule

All knowledge-tree mutation goes through YOps.

An LLM may propose a YAML operation list. A human or agent may edit that list.
But the deterministic engine is the only layer that applies it. Diff, merge,
validation, hash chains, and commit construction do not depend on an LLM.

## Current Alpha Surface

The current restricted alpha package surface is:

- `@t3x-dev/local`
- `@t3x-dev/yops`

Restricted package visibility is expected during this alpha. If an npm package
or release asset is not visible from an unauthenticated account, that usually
means you do not have access to the private/restricted alpha distribution.

CLI, MCP, API, WebUI, storage, core, and runner are available in this repository
for source development and preview, but they are not all promoted as public npm
entrypoints yet.
