# API Preview

:::caution Preview surface
The HTTP API is usable for self-hosted development and integration testing, but
it is not part of the current alpha package surface. Endpoint contracts
may change before promotion.
:::

This legacy URL is kept so older links do not break. For the current preview
page, see [API Preview](../preview/api).

Use the API preview when running the source stack:

```bash
pnpm dev:api
pnpm dev:webui
```
