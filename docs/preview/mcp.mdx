# MCP Preview

:::caution Preview surface
The MCP server is available for preview integrations with AI agents, but it is
not part of the current public alpha release surface. Tool names, inputs, and
authentication behavior may change before promotion.
:::

The MCP package exposes T3X workflows to MCP-compatible agents so they can
query, extract, edit, commit, diff, merge, and generate from semantic content.

Preview users should expect the API to evolve. The committed public alpha
surface remains `@t3x-dev/local` and `@t3x-dev/yops`.
