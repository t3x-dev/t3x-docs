# API Preview

:::caution Preview surface
The HTTP API is usable for self-hosted development and integration testing, but
it is not part of the current public alpha package surface. Endpoint contracts
may change before promotion.
:::

The API backs the WebUI and local product experience. It is useful when running
the source stack:

```bash
pnpm dev:api
pnpm dev:webui
```

Use this preview surface when you are developing against the monorepo or testing
self-hosted integration behavior.
