# CLI Preview

<DocBadges status="preview" verified="verified" />

:::caution Preview surface
The CLI is available for preview and internal workflow testing. It is not part
of the current alpha package surface, and commands may change before
promotion.
:::

The CLI is intended for command-line workflows around extraction, commits,
diffs, merges, and local workspace automation.

For the current alpha path without npm package access, start from source:

```bash
git clone https://github.com/t3x-dev/t3x-core.git
cd t3x-core
pnpm install
pnpm dev:api
pnpm dev:webui
```

If your npm account has restricted alpha access, you can use the packaged local
entry instead:

```bash
npx -p @t3x-dev/local t3x-local start
```

Use the CLI preview only if you are comfortable with changing commands and
contracts while the package is being stabilized.
