# CLI Preview

:::caution Preview surface
The CLI is available for preview and internal workflow testing. It is not part
of the current public alpha release surface, and commands may change before
promotion.
:::

The CLI is intended for command-line workflows around extraction, commits,
diffs, merges, and local workspace automation.

For the current public alpha path, start with:

```bash
npx -p @t3x-dev/local t3x-local start
```

Use the CLI preview only if you are comfortable with changing commands and
contracts while the package is being stabilized.
