# WebUI Overview

The T3X WebUI is the visual workflow for turning raw material into reviewed,
versioned meaning.

<img
  src="/img/screenshots/chat-light.png"
  alt="T3X WebUI in light mode"
/>

## Start it

For the packaged local alpha:

```bash
npx -p @t3x-dev/local t3x-local start
```

For source development:

```bash
pnpm dev:api
pnpm dev:webui
```

Open `http://localhost:3000`.

## Main workflow

1. Paste a prompt, transcript, release note, or design discussion.
2. Review the extracted meaning.
3. Commit the reviewed knowledge.
4. Reuse committed knowledge in leaves, diffs, and future work.
