# Workflows


Managing projects through the WebUI.

## Creating a Workflow

1. Click **"New Workflow"** button
2. Enter project name in the dialog
3. Click **Create**

## Browsing Workflows

The Workflows tab shows all projects with:

- Project name
- Creation date
- Statistics (turns, commits)

Click a workflow to open its detail page.

## Deleting a Workflow

1. Click the delete icon on a workflow card
2. Confirm the deletion

:::warning
This permanently deletes all data including turns, commits, and branches.
:::
