# Workflows

T3X starts from source material and moves toward durable semantic commits.

## Chat first

The `/chat` view is the first workspace. Paste material into the composer and
let T3X keep the source visible while extracting reviewable meaning.

## Review before committing

Extraction is not the final state. Review the proposed tree and YOps operations
before creating a commit. The deterministic engine applies the final operations,
so the committed state is auditable.

## Reuse committed meaning

After committing, the same knowledge can feed leaves, comparison views, and
future project work.
