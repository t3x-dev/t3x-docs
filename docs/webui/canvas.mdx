# Canvas Editor


Visual representation of conversations.

## Overview

The canvas displays turns and commits as connected nodes:

- **Turn nodes** — Individual messages
- **Commit nodes** — Semantic snapshots
- **Edges** — Relationships between nodes

## Interaction

- **Pan** — Click and drag on empty space
- **Zoom** — Scroll wheel
- **Select node** — Click on a node
- **View details** — Click node to open modal

## Node Modal

When you click a node, a modal shows:

- Full content
- Semantic rings (if turn)
- Facet snapshot (if commit)
- Metadata (timestamps, hashes)

## Semantic Cards

Semantic findings are displayed as cards showing:

- Entities (highlighted)
- Keywords (tags)
- Facets (categories)
