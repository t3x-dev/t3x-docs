# Canvas Workspace

The canvas is the visual workspace for committed meaning. It is useful after
you have source material, extracted knowledge, and at least one commit.

## What to look for

- Project context in the sidebar.
- Committed knowledge nodes.
- Commit and branch navigation.
- Leaf entry points for reusable outputs.

The canvas is not the first step for most users. Start in [Chat](./), review the
extracted meaning, then open the project workspace when you want to inspect the
semantic structure.
