# Quickstart

Start with the public alpha surface:

- `@t3x-dev/local` for the packaged local experience and no-key demo.
- `@t3x-dev/yops` for the deterministic YAML operation engine.

:::caution v0.3.0 publish pending
The v0.3.0 release is being prepared. The npm commands below are the intended
public entrypoints and become available after the publish workflow completes.
:::

Other packages in the monorepo are still restricted candidates until they are
promoted through the release surface process.

## Try T3X locally

```bash
npx -p @t3x-dev/local t3x-local start
```

This starts the local T3X experience. Open the printed local URL and use the
fixture demo if you want to explore the workflow without configuring a model
provider.

## Use YOps in your app

```bash
npm install @t3x-dev/yops
```

```ts
import { applyYOps } from '@t3x-dev/yops';

const input = {
  project: {
    status: 'draft',
  },
};

const result = applyYOps(input, [
  {
    set: {
      path: 'project/status',
      value: 'committed',
    },
  },
]);
```

YOps is deterministic: the same input document and same operation list produce
the same output or the same validation error.

## Develop from source

Use this path when contributing to T3X itself.

```bash
git clone https://github.com/t3x-dev/t3x-core.git
cd t3x-core
pnpm install
pnpm dev:api
pnpm dev:webui
```

The source WebUI runs at `http://localhost:3000`; the API runs at
`http://localhost:8000`.
