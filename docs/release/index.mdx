# Release Status

## Restricted alpha surface

| Package | Version | Status | Purpose |
| --- | --- | --- | --- |
| `@t3x-dev/local` | `0.3.1` | Restricted alpha | Packaged local T3X experience and no-key demo entrypoint. |
| `@t3x-dev/yops` | `0.3.1` | Restricted alpha | Deterministic YAML operation engine. |

Restricted package visibility is expected during this alpha. If an npm package
or runtime asset is not visible from an unauthenticated account, the account
probably does not have access to the restricted alpha distribution.

## Preview surfaces

CLI, MCP, API, and runner workflows are documented as previews. They are useful
for evaluation and integration work, but they are not part of the current
restricted alpha package surface.

## Current commands

```bash
npx -p @t3x-dev/local t3x-local start
npm install @t3x-dev/yops
```
