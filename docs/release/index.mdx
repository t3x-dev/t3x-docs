# Release Status

This page summarizes the public alpha package policy. Package availability,
runtime assets, and production-readiness are separate concerns.

## Alpha Package Surface

The release package surface is defined by
[`release/surface.yaml`](https://github.com/t3x-dev/t3x-core/blob/main/release/surface.yaml),
with [`RELEASE.md`](https://github.com/t3x-dev/t3x-core/blob/main/RELEASE.md)
as the human-readable release summary. The public alpha surface contains four
packages:

| Package | Access | Release train | Purpose |
| --- | --- | --- | --- |
| `@t3x-dev/local` | Public alpha | Paused | Existing local installer; runtime artifacts remain explicit. |
| `@t3x-dev/yops` | Public alpha | Active | Deterministic YAML operation engine. |
| `@t3x-dev/transition` | Public alpha | Active | Transition contracts, replay, identity, and integrity verification. |
| `@t3x-dev/yschema` | Public alpha | Active | Schema validation for structured state. |

Paused means excluded from default automated release preparation, not private
or unpublished. Public alpha is not a stable API or production-support promise.

For exact versions, consult the package registry and release records rather than
a shared documentation version banner. GitHub product releases
(`t3x-v*`) and runtime release assets are separate records; runtime GitHub
releases are expected for `@t3x-dev/local`, while `@t3x-dev/yops` is consumed
from npm.

This page records repository policy, not a live availability probe. If an install
fails, check the registry, requested version, network, and (for Local) matching
runtime assets. Do not assume restricted npm access is required. Source
development remains an alternative for evaluation.

## Preview surfaces

Core, API, storage, CLI, MCP, and runner workflows are documented as internal or
preview surfaces. They are useful for source development, self-hosted
evaluation, and integration work, but they are not part of the current
public alpha package surface. Public package access also does not establish
hosted Cloud launch readiness.

## Current commands

Source development:

```bash
git clone https://github.com/t3x-dev/t3x-core.git
cd t3x-core
pnpm install
pnpm dev:api
pnpm dev:webui
```

Public package commands (Local additionally depends on its runtime assets):

```bash
npx -p @t3x-dev/local t3x-local start
npm install @t3x-dev/yops
npm install @t3x-dev/transition @t3x-dev/yschema
```
